⚠️ Background

Booking recreational services in Karachi (futsal, padel, salons) is fragmented & manual. Customers contact vendors via WhatsApp, wait hours for replies, and restart from scratch if a slot is taken by another customer first.

🎯 Objectives
1
Bilingual NLU — Parse EN + Roman Urdu requests, handling variants like waqt / vakt / tym
2
Agentic Pipeline — LangGraph state machine manages slot locking, OCR payment verification & vendor approval autonomously
3
Concurrency Safety — Firestore OCC prevents double-booking across all channels simultaneously
4
Social Layer — Elo matchmaking, ranked leaderboard, community forum, friend system + DMs

Core research question: How can an AI agent understand & autonomously execute bilingual natural-language booking requests while guaranteeing consistency across a distributed multi-channel environment?

🏗️ What We Built
① Custom Bilingual Dataset
694 EN + Roman Urdu utterances from real Karachi vendor WhatsApp conversations. No pre-existing dataset existed.
② 6-Model NLU Evaluation
DistilBERT 90.5% acc, 91.7% F1 at 47ms CPU vs XLM-RoBERTa 70.5%. Compact wins on domain-specific tasks.
③ Production LangGraph Agent
Cyclic state machine with OCC, OCR verification, async WhatsApp state persistence. Zero hallucinated bookings.
④ Full-Stack Social Sports Platform
Pakistan's first bilingual agentic booking solution with Elo matchmaking, community forums, leaderboards. Live in production.
