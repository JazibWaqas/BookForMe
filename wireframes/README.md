# BookForMe Wireframes

## Overview
Complete set of low-fidelity wireframes for the BookForMe platform with navigation flows.

## Structure

### Created Files
- ✅ `USE_CASES_DOCUMENTATION.md` - Complete use case documentation
- ✅ `INDEX.html` - Master index of all wireframes
- ✅ `01_customer_registration_flow.html` - Login/Role selection
- ✅ `02_customer_registration_form.html` - Customer registration
- ✅ `03_registration_success.html` - Registration success
- ✅ `04_customer_browse_flow.html` - Browse flow
- ✅ `05_customer_home.html` - Customer home

### Remaining Files to Create
All remaining wireframes should be created using the user's provided HTML code with added:
1. Navigation arrows (green → for next, yellow ← for back)
2. Flow indicators showing current step
3. Click handlers for interactive elements
4. Proper navigation between related pages

## Navigation Pattern

Each wireframe includes:
- **Green Arrow (→)**: Next step in the flow (right side, bottom)
- **Yellow Arrow (←)**: Go back (left side, bottom)  
- **Flow Indicator**: Shows current step (top right)
- **Clickable Elements**: Navigate to related pages

## Usage

1. Open `INDEX.html` in a browser to see all wireframes
2. Click on any wireframe link to view it
3. Use navigation arrows to follow user flows
4. Click interactive elements to navigate between pages
