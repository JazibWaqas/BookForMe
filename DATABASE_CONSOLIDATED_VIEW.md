# JHAT Project: The Ultimate Database & Architectural Blueprint
**Last Updated**: February 20, 2026
**Status**: 100% Forensic Evidence Verified (V2.0)

This document is the **Canonical Forensic Map** of the JHAT (BookForMe) Firestore database. Every field listed here has been verified against the live database state.

---

## 🏛️ 1. Core Identity Layer

### 👤 `users` (Canonical User Schema)
*   **Document ID**: `uid` (Auth UID).
*   **Verified Fields**:
    *   `name`: string (Full Name)
    *   `phone`: string (Primary contact)
    *   `email`: string
    *   `role`: `"user"` | `"vendor"` | `"admin"`
    *   `vendor_id`: string -> `vendors.id`
    *   `avatar_url`: string
    *   `bio`: string
    *   **Gamification**: `points` (int), `level` (int), `badges` (array), `skill_rating` (number)
    *   **Social State**: `is_online` (bool), `last_active` (timestamp), `stats` (map)
    *   **Settings**: `preferences` (map), `password_hash` (string)
    *   `created_at`: timestamp

## 📅 2. Operations Layer

### 🏢 `vendors` (Business Entity)
*   **Document ID**: slug
*   **Verified Fields**:
    *   `name`: string
    *   `area`: string
    *   `address`: string
    *   `phone`: string
    *   `whatsapp_number`: string
    *   `description`: string
    *   `operating_hours`: map (`{mon: {open: "08:00", close: "00:00"}, ...}`)
    *   **Analytics**: `revenue_today`, `revenue_week`, `revenue_month`, `booking_count_today` (numbers)
    *   **Trust**: `average_rating`, `rating_count`, `rating_sum` (numbers)
    *   `default_payment_id`: string -> `vendor_payment_accounts.id`
    *   `created_at`: timestamp

### 🎾 `slots` (Inventory Ledger)
*   **Document ID**: `YYYYMMDD_HHMM_{vendor}_{resource_id}`
*   **Verified Fields**:
    *   `status`: `"available"` | `"locked"` | `"pending"` | `"confirmed"` | `"blocked"` | `"cancelled"`
    *   `vendor_id` / `service_id` / `resource_id`: strings (slugs)
    *   `start_time` / `end_time`: timestamps (UTC)
    *   `date`: string (`YYYY-MM-DD`)
    *   `price`: number
    *   `user_id`: string -> `users.id`
    *   `booking_source`: `"app"` | `"whatsapp_ai"` | `"manual"`
    *   `payment_id`: string -> `payments.id`
    *   `hold_expires_at`: timestamp (null if not locked)
    *   `updated_at` / `created_at`: timestamps

### �️ `services` (What is being sold)
*   **Verified Fields**: `name`, `sport_type`, `duration_min` (int), `pricing` (map/number), `active` (bool), `vendor_id`.

### 🏗️ `resources` (The physical court)
*   **Verified Fields**: `name`, `capacity` (int), `active` (bool), `vendor_id`.

### 💳 `payments` (The Audit Trail)
*   **Verified Fields**:
    *   `slot_id`, `vendor_id`, `user_id`: strings

### ⭐ `reviews`
*   **Verified Fields**: `vendor_id`, `user_id`, `slot_id`, `rating` (int), `title`, `content`, `status`, `created_at`.
