# Firestore Data Models

This folder documents the Firestore data models used in Slotify.

## Collections
- **users**: User profiles, bookings, reviews, chat history
- **vendors**: Vendor profiles, managed venues
- **venues**: Venue details, images, slots, reviews
- **slots**: Time slots for each venue, booking status
- **leaderboard**: Player stats and rankings
- **chat**: Chat history for AI and user conversations
