# Training Data Archive

This folder contains historical intent-classification datasets and fine-tuning
experiments.

It is not used by the current runtime booking agent.

Some generated datasets mention salons or older service categories. Treat those
as legacy training experiments, not active product scope.

Current runtime behavior is in:

- `backend/agent/`
- `backend/nlu/`
- `backend/scripts/booking_conversation_tests.py`
