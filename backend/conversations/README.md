# Conversation Research Archive

This folder is historical research material: example conversations, prompt
drafts, and analysis notes from earlier versions of the project.

It is not the current runtime prompt source.

Current runtime behavior lives in:

- `backend/agent/nodes.py`
- `backend/agent/graph.py`
- `backend/agent/tools.py`
- `backend/nlu/agent.py`

The active product is a sports court booking agent for padel, futsal, cricket,
and pickleball. Mentions of salons, Gemini prompts, generic appointments, or
older service taxonomies in this archive should not be treated as current
requirements.
